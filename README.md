# RIP / Family Chaos — لعبة المسابقات الجماعية (QuizMaster Hub)

لعبة مسابقات جماعية تفاعلية مبنية بأحدث تقنيات الويب (React 19 + TanStack Start + Tailwind CSS + Lucide Icons).

## المميزات
- شاشة رئيسية بهوية اللعبة وأسلوب برامج المسابقات.
- نظام النقاط: 200 و 400 و 600 نقطة لكل فئة.
- نظام التبديل ومنع تكرار الأسئلة مع حفظ الجلسات.
- عداد تنازلي، نظام السرقة (Steal)، وتحدي الرسم (Canvas).
- 15 فئة متنوعة تشمل معلومات عامة، الأردن، تاريخ، رياضة، سينما، جغرافيا وغيرها.

## طريقة التشغيل محلياً
```bash
git clone https://github.com/ripw2932-boop/quizmaster-hub.git
cd quizmaster-hub
npm install
npm run dev
```
